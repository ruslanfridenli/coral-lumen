# Coral Lumen — Neon Runner

A neon snake runner on a 24×24 grid at 10 ticks/s with wrap-around walls, plus 3 obstacles. Keyboard, touch and score persistence included.

## Features

- 24×24 grid gameplay
- Variable speed and wrap-around mode
- 3 obstacles for extra challenge
- Keyboard (arrows/WASD) and touch swipe controls
- Persistent best score via localStorage
- English/German interface

## Local development

```bash
git clone https://github.com/ruslanfridenli/coral-lumen.git
cd coral-lumen
# open index.html in a browser, or serve statically:
npx serve .
```

No build step, no dependencies — pure static site.
